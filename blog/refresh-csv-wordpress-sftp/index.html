CSV catalog updates

Refresh a WordPress CSV catalog with SFTP and a schedule

Keep a supplier catalog, directory, or listing up to date by replacing a CSV file on your server. Tabloria can refresh it when you click a button or check it on a schedule.

Set up a server CSVView the catalog demo

How it works

First, create a Tabloria Display from a CSV and publish it on a WordPress page. Then put an updated CSV in a private directory on the same server as WordPress. In the Display’s Data Source tab, point Tabloria at that filename.

SFTP is how you transfer the file to your hosting account. Tabloria reads the local file; it does not connect to a remote SFTP server or ask for your SFTP password.

Version: Server CSV refresh requires Tabloria 0.2.3 or later. Check the version on your WordPress Plugins screen before following these steps. The WordPress.org listing may serve an earlier version until the 0.2.3 update is published.

1. Prepare a private import directory

The default directory is tabloria-imports beside your WordPress installation. For example, when WordPress is in /home/account/public_html, create /home/account/tabloria-imports. The PHP process running WordPress needs read access.

Keep the directory outside your public website directory. If your host uses a different layout, set a private absolute path in wp-config.php:

define( 'TABLORIA_IMPORT_DIR', '/home/account/tabloria-imports' );

Put catalog.csv there by SFTP. When replacing it later, upload as catalog-uploading.csv and rename it to catalog.csv only after the transfer finishes. This prevents a scheduled check from reading a partial file.

2. Connect the CSV to a Display

  1. Open an existing Tabloria Display or create one by uploading a CSV.
  2. Open Data Source → CSV file on this server.
  3. Enter the filename relative to the private directory, such as catalog.csv or supplier/catalog.csv.
  4. Click Refresh now to import the file and verify that its headers still match your saved Display fields.

Every Display that uses the same source receives the new rows. A failed import leaves the previous rows available.

3. Choose manual or automatic refresh

For manual updates, leave Refresh automatically off and click Refresh now after each upload. For automatic updates, enable it, choose every 6 hours, 12 hours, day, or week, set the start time, and click Save source settings. Weekly checks also have a weekday setting.

Times follow the timezone under WordPress → Settings → General. A 6-hour schedule starting at 03:00 aims for 03:00, 09:00, 15:00, and 21:00. The Data Source tab shows the last check, last success, next planned run, and latest error. Scheduled checks skip an unchanged file.

Timing: Tabloria uses WP-Cron. WordPress starts scheduled work when the site receives a visit, so a quiet site may refresh later than the selected time. For precise timing, configure your host’s scheduler to trigger WordPress cron.

Common questions

Can I paste an SFTP URL or credentials?

No. Enter a relative filename for a CSV already on the WordPress server. Tabloria does not store SFTP credentials.

What happens if the new CSV has an error?

Tabloria rejects malformed files and replacements that remove existing column keys. The previous catalog remains available, and the Data Source tab shows the error.

Can the CSV live in public uploads?

No. Use a private directory outside the public website directory. Tabloria rejects public import directories and files that resolve outside the private directory.
